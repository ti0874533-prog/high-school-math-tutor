# 家教备课出题助手

Skill 只保存方法、模板和规则；学生数据存放于外部档案，题库放通用资料，年份、分值等保存在当前任务配置。英文调用名保留数学入口，中文显示名为“家教备课出题助手”，工作流程支持物理和其他学科。

## 按任务执行

1. 识别本次任务：单题检查、备课、出卷、错题诊断、档案初始化或更新。只做必要步骤，不自动启动完整教学流程。
2. 确定学生、学科、年级、教材或课程标准、知识模块、已学范围、目标、输出格式和难度。以用户本次明确要求为准，再参考已确认任务配置及档案；遇到关键冲突先澄清。缺少学生且学生选择影响结果时必须询问；通用讲解或单题检查可不绑定学生。非关键未知项标记“待补充”。
3. 需要学生背景时，先读取 `references/archive-locations.json` 的定位信息，再按学生编号和学科检索最少必要档案。公开版本默认未配置，不能据此声称存在档案或访问权限。需要历史时，按用户明确提供的路径读取外部私人定位配置；没有配置或定位失效时，请用户提供配置路径或 Drive 根目录及总索引链接。配置只用于本次授权任务，不写回公开 Skill。不得凭跨对话记忆还原成绩、进度或个人信息。多个同名目录需确认目标，不合并。未取得资料时可给条件式计划，不捏造基础。
4. 只在相关模式读取下列资源。引用档案中的证据编号、文件位置和记录日期；区分事实、推断、待确认。输出教学成果与待确认项；涉及长期档案时另列修改建议。

## 模式与资源

- 本地保存、查找资料或读取大型文档：按需读 [本地存储与按需读取](references/local-storage.md)，先读取小型路径配置和筛选后的索引；保存到用户配置的工作区，用户本次指定路径优先；未配置时先确认输出位置。不要启动时遍历资料库。
- 高考真题、正式模拟卷、专题练习与教学资料搜集：先读 [检索与地区策略](references/source-search-policy.md)。小红书优先发现，深圳及广东优先筛选；发现渠道不决定真实性，适配性与年份要求先于地区排序。
- 初始化学生、多科目归档、跨项目续用或准备云端更新：读 [档案与更新规则](references/archive-rules.md)，选用 `templates/学生档案.md`、`templates/科目档案.md`、`templates/变更建议.md`。未知信息只写“待补充”；预留代号不等于真实学生已登记。
- 备课、单题核验、其他学科扩展：读 [学科核验](references/subject-rules.md)，按需使用 `templates/教案.md`。教材和知识模块由本次资料决定，无须修改 Skill 核心文件。
- 正式练习或检测卷：读 [命题与题源](references/exam-rules.md)，使用 `templates/检测卷.md`、`templates/教师解析.md`、`templates/题源清单.md`。必须联网核验真实来源；离线只能提供明确标注的草案或原创题。只有计划或模拟测试时无需联网搜题。
- 错题、成绩和阶段规划：读 [诊断方法](references/diagnosis.md)，使用 `templates/课堂记录.md` 和 `templates/学情报告.md`。没有作答证据时不宣称发现薄弱点。

## 外部工具按需选择

备课、命题、错题分析、教学计划和教学档案读取等自然语言请求可按 description 自动匹配本 Skill，不要求用户输入 Skill 名称；是否实际加载仍由宿主决定。自动匹配不等于授权修改档案或对外行动。

- 只为当前任务选择必要能力，不逐一启动所有插件。例如通用备课无需学生历史时不查 Drive；单题检查无需真题检索时不联网；只输出文字计划时不生成文件。
- 需要学生历史时，优先检查当前已连接的 Google Drive，按定位配置读取最新学生总索引，用“学生编号＋科目”匹配唯一行，沿真实档案链接读取最新正文与版本。成功的实际只读请求才能证明当前可访问；不得用聊天记忆或旧本地占位记录替代。无法访问或匹配有歧义时报告并澄清，不静默回退或混合学生、科目。
- 需要真实高考题、模拟题或专题资料时，按检索与地区策略优先发现小红书公开资料，使用当前可用的 Firecrawl（搜索定位、抓取所需页面或原卷）或可靠联网工具；小红书无结果或不可访问时自动回退，不中断备课。按命题规则核验实际考试年份、题号、原分值、完整题面和来源；公式识别不可靠时对照原页。搜索摘要或抓取成功本身不等于题源已核实。
- 需要 Word、PDF 或 Excel 时，检查并使用当前可用的 documents、pdf、spreadsheets 等相应技能和文档处理工具，按其流程生成、重新打开并检查内容、公式和排版。仅调用所需格式的能力；生成本地文件不等于云端已保存，不自动上传或归档。
- 区分“已安装/工具可见”“已连接/可访问”“本次实际调用”“结果已核验”。连接、权限或工具不可用时如实报告具体错误、影响及所需连接/授权；可用替代工具时保持任务要求和核验标准，无法替代则说明未完成项。不要自动连接账号、反复重试同一失败操作或绕过安全限制。
- 交付时简要列出本次实际使用的 Skill、插件和工具、各自用途，以及已核验的关键结果与仍未验证的部分；没有调用的能力不记作已使用。

不得自动删除档案、联系家长或其他第三方、申请家教订单。学生档案的任何长期修改仍须先展示具体差异，取得用户明确确认后才写入；本 Skill 自动加载不改变这一要求。

## 成果与质量

数学独立重解并核对定义域、等价性、边界及评分点；物理核对模型、受力、方向、单位及适用条件。独立复核指不依赖既有答案重做推导，再对照；第二工具或他人复核只有实际发生才可声称。

DOCX 用于教案和试卷，PDF 用于打印定稿，XLSX/Google Sheets 用于统计，Markdown 用于轻量记录；按任务选择可用的 documents、pdf、spreadsheets 等技能，不依赖其必然存在。生成后读回并检查题答对应、公式图形、分值、分页、来源及学生版答案泄漏。无法渲染或打开时报告未验证项，不宣称可打印定稿。

有结构化出卷清单时执行 `python scripts/check_exam.py 清单.json`，清单字段见命题规则。该脚本只检查结构、分数和题源字段，不证明出处真实或答案正确。无清单时进行同等人工核对。

长期档案默认只读。本地与云端均先展示新增、修改、保留及依据，用户明确确认具体版本后才写入；遇到远端变化重新展示差异。写后读回，记录更新时间、依据、确认范围及结果；失败不得把索引标成更新成功。详见档案规则。普通草稿输出不等于写入长期记录。
