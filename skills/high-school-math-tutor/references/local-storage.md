# 本地保存与按需读取

只在任务需要本地文件或生成文件时读取 `local-storage.json`。公开版本的 `workspace_config` 为空：先用用户本次指定位置，或按其明确提供的外部配置路径读取 `workspace.json`；未配置时先确认输出目录，文字回答无须配置。外部私人配置放在公开仓库和 Skill 目录之外；不能把它写回公开 JSON。配置中的相对路径一律以该外部配置文件所在目录为基准，不相对于 Skill 或当前进程目录。用户本次指定路径优先；目录缺失、无权限或存在覆盖冲突时报告并请求所需授权，不猜测盘符或静默改用其他磁盘，不改 CODEX_HOME、全局下载目录、TEMP 或目录权限，不用链接重定向 Skill。

## 存储边界

- `paths.student_materials`：学生专属本地资料，按学生编号/科目分目录；仅在有实际文件时建立，不预建虚构学生。
- `paths.question_bank`：通用试卷和题库；`paths.teaching_materials`：讲义和课件。
- `paths.generated`：新生成的 Word、PDF、Excel 等成果；`paths.temporary`：处理用中间文件和渲染图；`paths.indexes`：目录、路径配置；`paths.backups`：回滚备份及保持旧布局的历史项目。
- Skill 原位保留小型规则、模板、脚本，不累积 PDF、历史资料或文档缓存。
- 用户已建立并验证 Google Drive 主库时，通过外部私人定位配置读取真实 IDs/链接；未配置则不能声称有主库。本地工作区不是自动同步盘；本地工作副本注明云端来源、版本和获取时间。任何历史快照不能代替正式学生档案。任何云端/长期学生档案修改仍须先展示具体差异并获得明确确认；同步前比较版本、时间和内容，不以旧本地副本覆盖新云端版本。不为迁移批量下载云端档案。

## 按需读取

1. 学生历史先查云端总索引，只取定位所需字段及指定学生/科目的匹配行，再沿真实链接读取该科目最新记录；发生重名/多行歧义时澄清。不读其他学生、其他科目正文。优先近期记录与摘要，相关性明确时再展开旧记录；摘要不足或相互矛盾必须回到原始证据。
2. 本地先在 `workspace.json` 的 `catalog` 指向的 JSONL 索引中，用学生编号、科目、模块、类型过滤元数据；先返回少量候选（通常不超过10条），再打开选中的文件。不把完整目录、题库或原始长文本塞入对话。无匹配时仅在本项目相关目录做有界搜索，不扫描个人盘符。
3. 索引只存路径、分类、大小、修改时间/哈希等定位信息，不复制正文，不把文件名推测成成绩或掌握程度。新资料按实际来源登记，重复内容用同一条路径引用。读取前检查文件存在及大小/修改时间，必要时核对哈希；失效条目按任务范围修正，不能把索引当成最终证据。
4. 大型 PDF 先查目录或本地定位关键词与页码，再只提取相关页；识别不可靠时渲染原页核对。需要全文查找时用本地脚本搜索并仅返回页码/短片段；无需把全文载入模型。
5. 原始题干、图形、条件、必要证明、评分与来源核验不能为节省 Token 而省略。按需加载相关模式的参考资料，不一次性读全套规则。
6. 用户若有历史项目，可在私人配置中指定 `history_roots`；公开包没有历史项目。仅在确需复用脚本时检查其工作目录、依赖和绝对路径；不要重跑旧初始化/建档脚本。历史候选题源不因迁移变成已核验题库；被舍弃资料不得直接用于教学。

## 复制和清理

迁移先生成清单、只复制不覆盖、核对数量/大小及哈希，再更新活动路径。原件保留；删除、批量覆盖、目录联接或改权限需单独授权。需要迁移时另建逐文件源/目标/哈希清单；回滚使用用户实际保留的备份和原件，不假设存在任何历史清单。清理历史副本前复查活动任务及绝对路径依赖，不自动删除。
