# 档案、隔离与更新

## 目录与标识

根目录下：00_学生总索引、01_学生档案、02_通用学科资料、03_通用模板与题库、04_任务配置。每位学生使用稳定编号（如 STU-A），名称仅作显示。索引一行对应一个学生—科目，不把不同科目拼成一个进度；多科学生分别登记。预留学生的科目为“待补充”，确认科目后替换预留行。

每位学生：基本信息与学情/学生档案.md；学科独立目录内有科目档案.md、教学进度与课堂记录、教案与讲义、练习与检测卷、错题与成绩分析、下一阶段教学计划。按需要新增学科和模块，不把示例目录当作已授课。基础档案仅共享经确认必要教学信息；无需保存住址、身份证、与教学无关的健康和家庭信息。

通用学科资料不含学生个人作答和成绩。私人作答不得放共享题库；抽取共性例题前移除学生标识。任务配置可引用学生编号，但只保存任务范围、年份、分值等，不写学情结论。

新学生只记录用户已提供字段，其他字段写“待补充”；不得默认已有成绩、已学知识或已授课。新增科目可复制科目模板，不能复制其他学生内容。原始作答单独保存，分析引用其路径/Drive ID、题号和日期。

## 证据与版本

事实：来自用户、教材、课堂记录或原始作答，并给出证据编号和位置。
推断：由这些证据作出的暂定解释，写清替代解释和验证方法。
待确认：缺失、冲突或无法辨认的信息。只有获得新证据或用户确认后才能转为事实。

记录字段：记录编号、学生编号、学科、发生日期、记录时间（含时区）、资料位置、事实/推断/待确认、内容、依据、确认状态。未提供上课日期时不能使用文件创建时间代替。成绩缺失不填 0。

文件可用 `YYYY-MM-DD_学生编号_学科_用途_vNN`；日期未知时用“日期待补充”，不要伪造上课日期。历史计划保留目标、执行状态（未开始/进行中/完成/调整）、证据和后续改动，不覆盖旧结论。

## 长期写入事务（本地与云端）

1. 检查真实目标、同名文件/目录和当前内容；Drive 搜索要遍历 next_page_token，按实际 parent ID 定位，不能只凭名称。只读取当前学生与学科必要文件。没有权限就停止相关操作，保留可审核草案。
2. 生成变更建议：目标路径或 ID、基线修改时间/版本或摘要、新增/修改/保留、数据依据、索引联动、预期结果。首次建立云端目录也先展示清单；仅在用户明确授权本次具体初始化范围后执行；安装公开 Skill 不构成建档或覆盖授权。
3. 用户明确确认具体范围后再执行；确认不授权其他学生、文件或共享操作。提交前重读基线，有变化就重新生成差异并确认。禁止自动连接账号、扩大共享、覆盖同名或改动无关文件。
4. 创建新版本或最小范围更新，保留原始证据和历史。多文件无事务时先详情、再日志、最后索引；逐项读回验证，部分失败列出已成功/失败/未执行项，不隐瞒部分写入，不自动删除回滚文件。
5. 日志记录实际 Asia/Shanghai 时间、操作、学生/科目、依据、用户确认、旧新版本、读回结果。索引只是导航摘要，不能替代详细档案。

## 云端接入与跨项目

工具可见不代表账号授权；先只读检查。成功搜索只证明该调用能读取，不能证明可写。未测试写入时标“写权限未验证”，不得声称云端已建立。只在已确认新建范围内验证实际写入并读回，不为探测权限制造无关文件。

云端成为主库前：确认账号/根文件夹；检查重名和已有记录；展示本地→云端映射及创建清单；确认后创建空目录并导入模板和总索引为原生 Google Sheets，读取结果记录真实 IDs/URLs。随后更新外部私人定位配置，不写回公开Skill。已有本地原件时，迁移失败应保留原件；没有既有档案时不得声称本地或云端系统已建立。

禁止宣称后台自动同步。云端设为主库后本地只能作注明版本时间的快照，写入前读主库避免双向覆盖。不同项目使用同一个定位配置并按需请求读取权限；Skill 的可发现性不等于档案访问权限。禁止把学生数据复制进 Skill 或依赖聊天记忆。
